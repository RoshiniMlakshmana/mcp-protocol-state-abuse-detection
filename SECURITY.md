# Security Policy

## Purpose of this project

This repository contains **defensive detection-engineering content**: a threat model,
telemetry contract, deterministic local test corpora, and Sigma/KQL/SPL detection rules for
protocol-state abuse in MCP (Model Context Protocol) Tasks and long-lived subscriptions.

It is intended for:
- security researchers and detection engineers evaluating MCP-based deployments,
- defenders building or extending MCP audit telemetry pipelines,
- **local, authorized testing only.**

## What this project is NOT

- It is not an exploit toolkit. All "attack" content (`data/attack/`) is synthetic, local,
  deterministic test data generated by `tools/harness/`, run only against a locally generated
  telemetry corpus — it never targets a live MCP server, real credentials, or third-party
  infrastructure.
- It does not ship a working attack tool against any real system.
- It does not claim to detect all MCP security issues (see `docs/threat-model.md` §16 and
  `docs/evasion-limitations.md` for explicit, documented limitations).

## Reporting a vulnerability

If you believe you have found:
- a security issue **in this project's own detection logic, telemetry design, or generator
  code** (e.g., a way the rules could be trivially bypassed that isn't already documented in
  `docs/evasion-limitations.md`), or
- a way this repository's content could be misused beyond its stated defensive purpose,

please open a **private security advisory** on this repository's GitHub Security tab
(`Security` → `Advisories` → `Report a vulnerability`) rather than a public issue, so any real
finding can be reviewed before public disclosure.

**No dedicated security contact email is configured for this project at this time.** If you
are unable to use GitHub's private security advisory feature, please open a regular GitHub
issue with the minimum detail necessary to establish contact, and a maintainer will follow up
to arrange a private channel — do not include exploit details or sensitive information in a
public issue.

## Responsible use

If you use this project's detection tracks or attack-simulation harness against systems you do
not own or do not have explicit written authorization to test, that use is outside the scope
and intent of this project. All included fixtures and harnesses are designed to run entirely
against locally generated, synthetic telemetry — never against a live third-party MCP server.

## Scope of "vulnerabilities" this project addresses

This project documents (but did not discover) a general MCP Tasks risk class already described
in SEP-2663 itself (task IDs functioning as bearer-token-like credentials) — see
`docs/threat-model.md` §10 and `docs/false-positive-analysis.md`. It is a detection-engineering
project, not a vulnerability-disclosure project for the MCP specification or any specific MCP
server implementation. If you discover an actual vulnerability in the MCP specification or a
specific MCP server/SDK, please report it to the relevant upstream project
(e.g., https://github.com/modelcontextprotocol/modelcontextprotocol for the specification, or
the specific SDK's own repository) rather than here.
